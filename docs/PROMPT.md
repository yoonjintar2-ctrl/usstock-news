# 미국주식 늬우스 — 초안·발행 규칙 (예약 작업은 이 문서를 먼저 읽는다)

발행인: 샌디스크 올인 · 기자: (필명을 정해 넣기) · 지면: https://stocknews.jintar.co.kr

## 절대 규칙
1. **숫자에는 출처와 기준 시각.** 시세·지수·환율·실적 숫자마다 `src`(URL)와 `asof`(예: `2026-11-19 16:00 ET 종가`)를 단다. 확인 못 한 숫자는 쓰지 않는다(빈칸 + "확인 중"). `scripts/check_numbers.py` 가 통과해야 발행한다.
2. **지어낸 인용·발언·숫자 금지.** 기사·리포트 문장 인용은 15단어 미만, 출처 하나에 인용 하나. 나머지는 내 말로 요약.
3. **투자 권유 금지(법적 선).** "사라/팔아라/목표가" 금지. "무슨 일이 있었나 · 왜 움직였다고 보도됐나"만. 매 호 하단과 영상 설명에 「투자 권유가 아니며, 투자 판단과 책임은 본인에게 있습니다.」 — 불특정 다수에게 특정 종목 매매를 권하면 유사투자자문업 문제가 될 수 있다. 창간 전 전문가 확인.
4. **달러 → 원화.** 달러 금액에는 그날 환율로 대략의 원화를 함께(예: 3,700만 달러, 약 540억 원). 환율 출처·시각 표기.
5. **색에 기대지 않는다.** 국장(빨강=상승)과 미장(초록=상승) 색이 반대라 헷갈린다. ▲▼와 +/- 숫자로 표시, 하락은 막대보다 말로.
6. **오늘 호(today.json, archive/오늘) 수정 금지** — 초안은 drafts/ 에만.
7. **권한 요청 금지(무인 작업).** 페이지 열기·브라우저·컴퓨터 사용을 쓰지 않는다. 웹 검색 결과(제목·요약·URL)로만 확인하고, 막히면 건너뛰고 보고한다.

## 하루 일정 (KST, 미장 정규장 마감 = 서머타임 05:00 / 그 외 06:00)
| 시각 | 단계 | 하는 일 |
|---|---|---|
| 20:40 | 초안 | `drafts/D.json` 틀: 실적 달력·경제 지표 예정·한 줄 용어·그날의 증시·퀴즈. 시세 칸은 비워 둠. 그림 `ai` 프롬프트. 음성 작업 파일 |
| 22:10 | 맥 넣기 | 음성(us-…)·그림(zz-us-img-…) 작업을 qtts/jobs/ 에. 중복 확인 |
| 06:10 | 채우기·거두기 | 마감 시세·지수·환율·특징 종목을 웹 검색으로 확인해 숫자 칸 채움(출처·시각) → check_numbers → 음성·그림 거둠 |
| 06:40 | 영상 | 렌더 → qa → 업로드(docs/PUBLISH.md) |
| 07:10 | 발행 | publish_draft.py → 공유 카드 → 390px·1400px 화면 확인 → 보고 2~3줄 |

시세 숫자가 들어가는 문장(영상 대본)은 06:10 에 확정되므로, 밤에 미리 읽혀 두는 음성은 숫자 없는 문장만. 숫자 문장은 06:10 에 짧게 따로 읽힌다(테이크당 20~55초 — 문장 수를 12개 안으로).

## 코너와 분량 (숫자는 짧게, 이슈는 다양하게)
- **1면 사설**(`editorial`): 발행인 샌디스크 올인(@SNDK_lover)이 최근 올린 쇼츠 1편을 바탕으로. 긴 글 금지 — 큰 숫자 카드 4~5개(`figures`: n·won·t·src) + 발행인 시각 3문장(`view`) + 「이 시나리오가 틀리는 경우」 3줄(`risks`). 희망 시나리오지만 확정 예측처럼 쓰지 않는다. 쇼츠 id 를 `short` 에.
- **발행인 칼럼**(`column`): 두 번째 쇼츠로 3문장.
- **밤사이 미장**(`market`): S&P·나스닥·다우·필라델피아 반도체·러셀 2000 + 한 줄 해설.
- **참고 지표**(`gauges`, `macro`): 공포·탐욕(CNN), 12월(다음 회의) 금리 인상·인하 확률(CME FedWatch 보도), VIX, 풋/콜 · 미 국채 10년(%p 변화), 달러인덱스, WTI, 원/달러.
- **차트 분석**(`charts`, `chart_summary`): `scripts/chart_analysis.py` 가 나스닥·S&P 500·SOXX 일봉으로 20·50·200일선 위치, 200일선 돌파/이탈 자리, 골든·데드크로스, 52주 고점 대비, 20일 지지·저항, 거래량(QQQ·SPY·SOXX 20일 평균 대비), RSI 를 계산. 문장은 계산값에서만.
- **간밤 핵심 뉴스**(`news`): 5~6건, 건마다 2문장 + 출처.
- **특징주**(`movers`): 4~6종목, 이유 한 줄.
- **월가·연준 한마디**(`street`): 증권사 투자의견·목표주가 변경(보도된 사실, 이전→이후, 원화 병기), 연준 인사·큰손 발언 요약. 권유 문장 금지.
- **오늘 밤 일정**(`schedule`): 한국 시간, 중요도 ★1~3. 실적 달력(`earnings`)은 이번 주.
- 한 줄 용어(`term`) 100자.

## 시세 데이터 받는 법
클라우드 작업 공간은 야후 파이낸스가 막혀 있다. 맥(또는 PC) 크롬이 연결된 대화에서 `docs/DATA-FETCH.md` 의 스크립트를 query1.finance.yahoo.com 탭에서 실행해 `data/raw_series.txt`·`data/summary.txt` 를 만든 뒤 `chart_analysis.py` 를 돌린다. 끝나면 탭을 닫는다.

## 그림 (AI 삽화 · 맥 SDXL-Lightning)
- 그림은 썸네일·대표 이미지만. 지면의 주인공은 데이터 차트.
- `ai` 프롬프트는 영어 60단어 안, 화풍 문구는 스크립트가 맨 앞에 붙임. 실존 인물 얼굴·회사 로고·제품 실물 그리지 않음(건물 외관·사무실·추상적 장면).
- 고를 때: 실제 사물·시대와 맞나 눈으로 확인. 엉뚱하면 쓰지 않는다. AI 가 모르는 물건은 밑그림(init) 방식.
- 움직임: `animate.py` 8초 한 바퀴 루프(이음매 없음).
