# 영상 렌더 · 검수 · 유튜브 업로드

문학늬우스 `docs/YOUTUBE-UPLOAD.md` 를 줄인 것. 스크립트는 `scripts/from-munhak/shorts/` 를 이 신문 형식에 맞게 고쳐 쓴다.

1. 대본: `shorts/scripts/D.json` — 첫 2초에 종목/인물 + 숫자, 숫자는 today.json 과 같게, 마지막에 지면 소개.
2. 나레이션: 숫자 없는 문장은 전날 밤, 숫자 문장은 06:10 에 맥 대기기로. 티커·숫자는 한글로 풀어 씀(엔비디아, 삼백이십 달러).
3. 렌더: 세로 1080×1920, 3분 안(쇼츠). CPU 2개라 한 편씩.
4. 검수: `qa_video.py` — 음량·무음·자막 속도·본문 일치·길이 → `.qa.png` 를 Read 로 직접 본다.
5. 썸네일: 한 컷 + 후킹 문구 2줄, 매번 같은 틀 피하기.
6. 파일 옮기기: 임시 고아 브랜치 `video-upload` 에 mp4·썸네일·srt·설명 txt force-push(100MB 넘으면 `ffmpeg -crf 25`).
7. 업로드(맥 크롬, Studio): JS 로 파일 넣기 → 제목·설명 → 썸네일 → 아동용 아님 → 재생목록(드롭다운 순서가 바뀌니 확대해 확인) → 공개. 이미 올린 영상인지 먼저 확인, 일일 한도에 걸리면 24시간 대기.
8. 설명 맨 끝: 출처 목록 + 「투자 권유가 아니며, 투자 판단과 책임은 본인에게 있습니다.」
9. 끝나면 원래 채널로 계정 되돌리고 탭 닫기.
