개인정보처리방침

미국주식 늬우스(stocknews.jintar.co.kr)와 유튜브 채널 '샌디스크 올인'(이하 '서비스')의 개인정보처리방침입니다. 시행일: 2026년 11월 27일

1. 수집하는 정보

서비스는 방문자나 시청자의 개인정보를 수집하지 않습니다. 회원가입, 로그인, 댓글 입력 기능이 없습니다.

2. 구글 API 사용

서비스의 업로드 도구(sandisk-allin-uploader)는 채널 운영자 본인의 유튜브 계정에 운영자가 만든 영상을 올리는 데에만 YouTube Data API를 사용합니다. 운영자 본인 외의 구글 계정 정보에는 접근하지 않으며, 받은 인증 정보는 운영자의 비공개 저장소 설정에만 보관하고 다른 곳에 공유하거나 판매하지 않습니다. 구글 API로 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. 쿠키와 외부 서비스

사이트는 광고·추적 쿠키를 쓰지 않습니다. 사이트를 호스팅하는 GitHub Pages가 서버 운영을 위해 접속 기록을 남길 수 있습니다.
